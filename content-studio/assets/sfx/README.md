# SFX (Sound Effects)

El pipeline busca estos 3 archivos al renderizar el reel.
Si alguno falta, el reel se renderiza sin ese SFX (sin romper).

Archivos esperados (MP3, max 2 segundos cada uno):

- `whoosh.mp3` — se reproduce en cada transición entre escenas
- `click.mp3` — (opcional) para accent breves
- `ding.mp3` — se reproduce al empezar el outro branded

## Dónde bajarlos gratis

- [Mixkit Transitions](https://mixkit.co/free-sound-effects/transitions/) — sin login, licencia comercial OK
- [Freesound.org](https://freesound.org/) — requiere cuenta gratis, muchos CC0
- [Pixabay SFX](https://pixabay.com/sound-effects/) — gratis comercial

## Recomendación concreta

1. **whoosh.mp3**: [Mixkit: Cinematic trailer whoosh](https://mixkit.co/free-sound-effects/whoosh/)
2. **ding.mp3**: [Mixkit: Interface hint ding](https://mixkit.co/free-sound-effects/notification/)

Bajá, renombrá a `whoosh.mp3` y `ding.mp3`, ponelos acá.
