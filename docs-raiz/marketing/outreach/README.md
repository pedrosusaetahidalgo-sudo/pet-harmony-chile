## Flujo recomendado antes de enviar

### Para cada prospecto

1. **Leer** [ESTRATEGIA_LAUNCH_SUPPORTERS.md](ESTRATEGIA_LAUNCH_SUPPORTERS.md) para tener framework fresco.
2. **Abrir** la propuesta personalizada del prospecto.
3. **Verificar** que los números, fechas y links están actualizados.
4. **Revisar** el deck HTML linkeado (visit https://pawfriend.cl/pitch/companys.html o /voices.html) en el mismo browser donde el prospecto lo va a abrir — ¿se ve bien en mobile?
5. **Leer en voz alta** el mensaje de introducción. ¿Suena Pedro o suena corporativo falso?
6. **Enviar** por el canal correcto (correo formal para Companys, DM/WhatsApp para Voices).
7. **Registrar** en el Admin panel (si hay tabla de outreach) o en una hoja de Google: fecha, prospecto, canal, respuesta esperada.

## Si recibes un "no"

Está bien. Cada "no" ahora es un "sí" potencial en 6-12 meses cuando
vean el proyecto funcionando con tracción. Mantén la puerta abierta:

- Responder con gratitud, sin insistir.
- Marcar en el CRM interno con `status: cold / follow_up_Q4`.
- En 6 meses, re-contactar con update de métricas reales.

**No hay prospecto quemado si cerraste con elegancia.**
