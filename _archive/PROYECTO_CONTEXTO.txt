PROPUESTA DE VALOR (REDEFINIDA)
========================================

Paw Friend evolucionó de "red social para mascotas" a una plataforma de doble cara:

1. B2C — Dueños de mascotas: red social, gestión de salud, mapas, adopción,
   gamificación.
2. B2B — Veterinarios independientes y clínicas (NÚCLEO DEL MODELO DE NEGOCIO):
   directorio público con SEO, sistema de reseñas verificadas, reservas online,
   perfil profesional compartible.

PIEZA CENTRAL DEL PRODUCTO: el directorio público de veterinarios en /veterinarios.
Cualquier persona —sin login— puede buscar, filtrar y ver perfiles de vets con
reseñas verificadas. Cada vet tiene una URL única (pawfriend.cl/veterinarios/dr-juan-perez)
compartible en WhatsApp, Instagram y Google. Esto es lo que justifica el plan pago
del vet y genera tráfico orgánico para la plataforma.

========================================

- Frontend: React 18 + TypeScript + Vite
- Styling: Tailwind CSS + shadcn/ui (50+ componentes)
- State: TanStack React Query + React Context
- Forms: React Hook Form + Zod

- Maps: Google Maps API + Leaflet
- Backend: Supabase (Postgres + Auth + Storage + Edge Functions Deno)
- Auth: Supabase Auth (Google OAuth, Facebook OAuth, Email/Password)
- AI: Claude API (Anthropic) vía Edge Functions
- Pagos: Webpay Plus (Transbank Chile)
- Mobile: Capacitor (iOS/Android)
- Deploy: GitHub Pages (docs/ folder) en pawfriend.cl

FLUJOS DE USUARIO PRINCIPALES
========================================

FLUJO 1: Vet nuevo se registra
  Landing → Click "Soy veterinario"
    → /registro-veterinario
       Paso 1: Tipo (individual/domicilio/clínica)
       Paso 2: Cuenta (signUp + crea profile)
       Paso 3: Mini-perfil (bio, especialidades, comunas)
       Paso 4: Listo + URL pública asignada
    → /provider/profile-edit (completar al 80%)
    → Activar "Aparecer en directorio" (switch)
    → Aparece en /veterinarios

FLUJO 2: Dueño busca veterinario (sin cuenta)
  Google → /veterinarios/comuna/las-condes (SEO orgánico)
    → Filtra por especialidad/rating
    → Click perfil
    → Lee reseñas, ve precios
    → Click "Reservar" → /auth?returnTo=... (registro)

FLUJO 3: Vet invita a paciente off-platform a dejar reseña
  Vet → /provider/dashboard
    → ProviderDirectoryCard → Botón "Invitar paciente"
    → Modal: nombre + email opcionales
    → Genera link único /resena/{token} (válido 30d)
    → Botón "Enviar por WhatsApp" con mensaje pre-redactado
  Paciente → Recibe link
    → /resena/:token
    → Si no logueado: /auth?returnTo=/resena/:token
    → Form: estrellas + título + comentario
    → Submit → reseña con verification_type='invitation'
    → avg_rating del vet se recalcula vía trigger

FLUJO 4: Admin verifica Colmevet
  Vet pone license_number en su perfil → queda is_verified=false
  Admin → /admin → Tab "Vets Colmevet"
    → Lista de pendientes con link a colegioveterinario.cl
    → Click Aprobar → is_verified=true + badge ✓ aparece en perfil público
    → Click Rechazar → escribir motivo → guarda rejection_reason

NORTE ESTRATÉGICO
========================================

El éxito de Paw Friend depende de tres cosas, en este orden:

1. Que vets reales completen su perfil al 80% y lo activen.
   Sin vets en el directorio no hay producto.

2. Que cada vet comparta su URL pública en WhatsApp/Instagram.
   Esto trae tráfico orgánico cero-costo y construye reputación.

3. Que las reseñas sean creíbles (verificadas por reserva o por invitación con
   disclaimer claro).
   Sin confianza no hay conversión.

Toda decisión de producto debe medirse contra estas tres métricas:
- % de vets activos en directorio
- Shares de URL pública
- Reseñas publicadas/mes
