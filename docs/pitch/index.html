Cómo se usan estos decks

Por link (recomendado): pega la URL directa del deck en WhatsApp, email o LinkedIn. El receptor verá un preview rico (imagen + título + descripción). El link siempre muestra la versión más actualizada.

Por PDF (formal): abre el deck en Chrome/Edge, presiona Ctrl+P (o ⌘+P), destino Guardar como PDF, margen ninguno, gráficos de fondo activado.

Por teclado en reunión: usa ↓ / ↑ para navegar slide por slide, F11 para pantalla completa.
